# Ozon GMV 商品采集助手

当前测试版支持在 GMV 采集箱粘贴 Ozon 或 1688 商品详情页链接批量采集。1688 会读取标题、主图、供货价、可见属性、规格和店铺来源；Ozon 会读取公开商品页上的标题、图片、售价和可见属性。

## 安装

1. 在 GMV 的“商品发布 → 采集插件”下载 ZIP 并解压。
2. 打开 Chrome `chrome://extensions`，启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中解压后的 `ozon-gmv-collector` 文件夹。
4. 回到 GMV 采集箱，点击“一键采集”，粘贴 Ozon 或 1688 商品详情链接（每行一个，最多 50 条）并提交。插件会逐条在后台读取页面并将结果保存到采集箱。

工具栏图标提供插件状态和打开 GMV 采集箱入口。更新插件后在 Chrome 扩展管理页点击扩展卡片上的刷新图标，再刷新已打开的 GMV 页面。

扩展只把商品采集快照传给当前浏览器里的 GMV 工作台；上架仍在 GMV 中由用户编辑、预检并确认。
